# Third-party licenses

Silex STD includes generated data derived from the Unicode 17.0.0 Character
Database. That data remains subject to the Unicode License V3, whose complete
text is stored in [Unicode.txt](Unicode.txt).

The generated source identifies its origin in `Module/Text/Data.sx`. The
license in the repository root covers only the original Silex STD work and
does not replace or relicense this third-party material.

The checked-in `CryptoPrimitives` archives are built from cryptographic
implementations in the Zig 0.16 standard library. Zig's MIT license is stored
in [Zig.txt](Zig.txt).
